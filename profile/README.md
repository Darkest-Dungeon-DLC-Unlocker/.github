## **How to Use**

1. Download the latest **CreamAPI** from the Releases page
2. Run the application (no installation required)
3. Select your Darkest Dungeon folder
4. Choose the DLC you want to install
5. Press **Update**

---

## **Troubleshooting**

### **Game not detected**

* Select folder manually using **Browse**

### **DLC not showing in game**

* Run **Repair**
* Confirm the DLC folders exist in the game directory
* Restart the game

### **Multipart archive errors**

* Install **7-Zip**
